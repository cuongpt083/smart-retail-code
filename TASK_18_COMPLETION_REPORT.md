## ✨ Design Principles (Followed)

### ✅ "Ngắn Gọn" (Brief)
- Short paragraphs (2-3 lines)
- Bullet points for lists
- Code examples instead of long explanations
- Headings for easy scanning

### ✅ "Dễ Hiểu" (Easy to Understand)
- No jargon (or explain if must use)
- Analogies to real life (pizza, store owner)
- Visual structure (emoji, tables, ASCII)
- Vietnamese primary + English supplements
- Step-by-step instructions

### ✅ "Học Sinh Lớp 11" (Grade 11 Students)
- Assume no programming background
- Assume no advanced technical knowledge
- Use relatable examples (store, phone, friends)
- Explain "why" not just "how"
- Encourage exploration & mistakes

**Day 1 (30 min):**

1. Play with dashboard (explore tabs)

**Week 1 (30 min):**
1. Connect Zalo OA (see `API_BASICS.md`)
2. Read `DEPLOYMENT_STUDENT.md`
3. Deploy to Streamlit Cloud

**Ongoing:**
- Refer to troubleshooting for errors
- Use code examples as reference
- Check deployment guide if scaling
